# Python Data Structures

This folder contains Python programs demonstrating the four major built-in data structures: Lists, Dictionaries, Sets, and Tuples.

## Topics Covered

### 1. Lists

File: `lists.py`

Lists are ordered and mutable collections that allow duplicate elements.

Concepts covered:
- Creating lists
- Accessing elements using indexing
- List slicing
- Adding elements using `append()`, `insert()`, and `extend()`
- Removing elements using `remove()`, `pop()`, and `del`
- Sorting and reversing lists
- Looping through lists
- List comprehension
- Nested lists
- Copying lists

### 2. Dictionaries

File: `dictionaries.py`

Dictionaries store data in key-value pairs. They are ordered and mutable.

Concepts covered:
- Creating dictionaries
- Accessing values using keys and `get()`
- Adding and updating items
- Removing items using `pop()`, `popitem()`, and `del`
- Dictionary methods: `keys()`, `values()`, and `items()`
- Looping through dictionaries
- Checking whether a key exists
- Nested dictionaries
- Copying and clearing dictionaries

### 3. Sets

File: `sets.py`

Sets are unordered collections of unique elements.

Concepts covered:
- Creating sets
- Adding elements using `add()` and `update()`
- Removing elements using `remove()`, `discard()`, and `pop()`
- Checking membership
- Union
- Intersection
- Difference
- Symmetric difference
- Subset and superset
- Removing duplicates from lists

### 4. Tuples

File: `tuples.py`

Tuples are ordered and immutable collections that allow duplicate elements.

Concepts covered:
- Creating tuples
- Single-element tuples
- Accessing elements using indexing
- Tuple slicing
- Tuple methods: `count()` and `index()`
- Looping through tuples
- Tuple packing and unpacking
- Nested tuples
- Concatenation and repetition
- Converting lists into tuples and vice versa
- Tuple immutability

## How to Run

Open the terminal in the root directory of the repository and execute the programs individually:

```bash
python 06_datastructures/lists.py
python 06_datastructures/dictionaries.py
python 06_datastructures/sets.py
python 06_datastructures/tuples.py
```

## Key Learning Outcomes

After completing these programs, you should be able to:
- Understand the four major Python data structures.
- Store, access, and manipulate collections of data.
- Perform common operations using built-in methods.
- Understand the differences between mutable and immutable collections.
- Choose the appropriate data structure for different programming tasks.
