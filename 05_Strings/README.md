# Python Strings

This folder contains Python programs demonstrating string formatting, string methods, and string slicing.

## Topics Covered

### 1. String Formatting

File: `string_formating.py`

Learn different ways to format strings and display variable values.

Concepts covered:
- Basic string formatting
- f-strings
- `format()` method
- `%` formatting
- Decimal precision
- Text alignment
- Leading zeros
- Percentage formatting
- Number formatting with commas

### 2. String Methods

File: `string_methods.py`

Learn built-in methods used to manipulate and examine strings.

Concepts covered:
- Changing case using `upper()`, `lower()`, and `title()`
- Removing whitespace using `strip()`, `lstrip()`, and `rstrip()`
- Searching using `find()`, `index()`, and `count()`
- Replacing text using `replace()`
- Splitting and joining strings
- Checking string content using `isalpha()`, `isdigit()`, and other methods
- Aligning text using `ljust()`, `rjust()`, and `center()`
- Understanding string immutability

### 3. String Slicing

File: `string_slicing.py`

Learn how to extract specific parts of a string using indexes.

Concepts covered:
- Positive and negative indexing
- Basic slicing
- Start, stop, and step
- Omitting start and stop indexes
- Reversing strings
- Extracting substrings
- Slicing with variables
- Understanding string immutability

## How to Run

Make sure Python is installed on your system.

Open the terminal in the root directory of this repository and run the programs individually:

```bash
python 05_strings/string_formating.py
python 05_strings/string_methods.py
python 05_strings/string_slicing.py
```

## Key Learning Outcomes

After completing these programs, you should be able to:
- Format strings using different techniques.
- Use common built-in string methods.
- Extract characters and substrings using slicing.
- Reverse strings and work with indexes.
- Understand that Python strings are immutable.
